# Taskbar Media Overlay

A lightweight always-on-top widget that sits on your taskbar and shows whatever's
currently playing title, artist, album art, and a progress bar. Works
with Spotify, YouTube in a browser tab, VLC, and anything else that reports
to Windows' media controls.

Settings (which monitors to show it on, position, etc.) are in the system
tray icon - right-click it.

## Requirements

- Windows 10/11
- Python 3.9+

## Setup

```bash
pip install -r requirements.txt
python main.py
```
